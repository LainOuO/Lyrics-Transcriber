# 歌词提取器

从音频文件中提取歌词，生成配套的 `.lrc` 文件（与音频同目录、同名，播放器可自动加载）。

## 支持的格式

`.mp3` / `.flac` / `.wav` / `.m4a` / `.mp4` / `.aac` / `.ogg` / `.opus` / `.wma` / `.ape` / `.aiff` / `.aif`

各容器的标签体系与歌词字段：

| 格式 | 标签体系 | 歌词字段 |
| --- | --- | --- |
| mp3 | ID3 | `SYLT`（同步）> `USLT`（纯文本） |
| wav / aiff | 容器内嵌 ID3 | `SYLT` > `USLT` |
| flac / ogg / opus | VorbisComment | `LYRICS` / `UNSYNCEDLYRICS` |
| m4a / mp4 | MP4 | `©lyr` |
| wma | ASF | `WM/Lyrics` |
| ape | APEv2 | `Lyrics` |
| aac | ADTS 裸流 | 无标签标准，自动走文件名回退 + 在线查询 |

任何格式的内嵌歌词，只要整段本身是 LRC 文本，都会自动还原出时间轴。

## 歌词来源（按优先级）

1. **内嵌歌词标签**：优先读取带时间轴的同步歌词（mp3/wav/aiff 的 `SYLT`），其次纯文本歌词
   （`USLT`、`LYRICS`、`©lyr`、`WM/Lyrics`、`Lyrics` 等）；若文本内本身带有 `[mm:ss.xx]`
   时间戳，也会解析为同步歌词。
2. **在线兜底**：内嵌没有时，按“歌名 + 歌手 + 时长”查询 [lrclib.net](https://lrclib.net)
   免费公开歌词接口，优先取带时间轴的版本。
   - 先试 `/get` 精确匹配，再按三轮 `/search` 兜底：①「歌手 + 歌名」→ ②「仅歌名」→
     ③「歌名罗马字」（`ひとひら` → `hitohira`，需 `pykakasi`，未安装则自动跳过）。
     日文曲目在 lrclib 上常常只有罗马字条目，②③两轮专门用来兜这种。
   - ②③两轮丢掉了歌手这个锚点，因此**强制要求时长落在 3 秒容差内**才敢认领；
     本地时长未知时直接不做这两轮——宁可查不到，也不把别人的歌词写进文件。
   - 接口高峰期会返回 503（`ServerOverloaded`），这类瞬时故障以及网络抖动、429、
     其余 5xx 都会自动退避重试（默认 3 次、0.8s 起翻倍），重试仍失败才计入「处理失败」。
3. **AI 听歌转写（可选，v0.5.0 起）**：勾选「AI 兜底」后，内嵌与在线都拿不到的文件
   交给语音识别服务，把歌里唱的词听写出来。词级时间戳拼成同步歌词；服务只给纯文本
   时降级为纯文本歌词。**每首都先弹预览窗，改完错字确认才写入 .lrc**（详见下文
   「AI 兜底」一节）。
4. **失败清单**：以上都拿不到的文件记入失败清单，可在界面上导出为 txt，
   也可挑出来交给 AI 转写。

标题缺失时，按 `歌手 - 标题.<扩展名>` 的文件名习惯回退解析出标题/歌手再查在线。
拿不到时间轴时降级输出纯文本行（无时间戳的 LRC），并在日志中标记。

## 使用

开发模式运行（需要 Python 环境）：

```bash
python -m lyrics_extractor
```

界面顶部先用「提取范围」选择处理对象，两种模式共用下面的「覆盖已有 lrc」「在线兜底」选项：

| 模式 | 选择方式 | 提取行为 |
| --- | --- | --- |
| **整个文件夹**（默认） | 「浏览…」弹目录选择框，或直接粘贴路径 | 扫描文件夹下所有受支持格式的音频，逐个提取；「包含子文件夹」决定要不要连子目录一起扫 |
| **单个文件** | 「浏览…」弹文件选择框（已按支持格式过滤），或直接粘贴路径 | 只处理这一个文件，进度为 1/1；该文件已有同名 lrc 且未勾选「覆盖已有 lrc」时记为「已存在跳过」 |

两种模式各自的路径会分别记住，来回切换不会丢；「包含子文件夹」在单个文件模式下自动置灰（不适用）。
提取过程中「提取范围」「浏览」「开始提取」都会锁住，避免中途换目标对不上日志。
单个文件模式下选到非支持格式（比如 `.txt`）会直接弹窗拦下，不会静默跳过。

### AI 兜底（听歌转写）

内嵌和 lrclib 都查不到的歌——翻唱、自录、冷门曲目——可以交给语音识别 AI 直接听歌写词：

- **触发**（两种任选）：
  1. 勾上「AI 兜底」正常开始提取，查不到的歌自动逐首转写；
  2. 跑完后点「AI 提取失败项…」，从失败清单里挑歌（可多选）再转写。
- **预览确认**：每首转写完都会弹预览窗，改完 AI 听错的字再点「保存 .lrc」。
  保留行首时间戳就是带时间轴的歌词；把时间戳全删掉则保存为纯文本歌词。
- **服务配置**：点「AI 设置…」填写。默认 **Groq**——在
  [console.groq.com](https://console.groq.com) 免费注册即可拿到密钥，转写有免费额度
  （按音频时长限流，日常个人使用足够），支持词级时间戳。任何 OpenAI 兼容的转写服务
  都能接：改「接口地址 / 模型名 / 密钥」即可。
- **隐私与限制**：云端转写会把音频文件上传给服务商；单文件超过 25MB 会被拒收并明确
  提示（无损大文件常见，如 FLAC 整轨）。设置（含密钥）明文保存在本机
  `~/.lyrics_extractor/settings.json`，不联网、不进代码仓库。
- **服务商现状**（2026-10 实测）：智谱 GLM-ASR 单次只收 30 秒音频，不适合整首歌；
  硅基流动已下架全部转写模型；两者暂不可用。讯飞 / 阿里等国内带词级时间戳的服务
  留作后续适配。

### AI 增强包（可选，进阶用户）

以下增强只对**源码方式运行**（`python -m lyrics_extractor`）生效；安装版 exe
为了控制体积没有打包这些 1GB 级依赖，只能用云端引擎。

- **本机离线转写**：`pip install whisper-timestamped`（还需要本机装有 ffmpeg），
  然后在「AI 设置」里把引擎切到「本机模型」。模型首次使用时自动下载并缓存，
  之后断网也能转写。
- **人声分离**（背景音重的歌转写更准）：`pip install demucs`，并勾选「人声分离增强」。
  转写前先把人声从伴奏里剥出来；没装依赖会自动跳过，不影响主流程。
  注意 CPU 分离一首歌通常要几分钟，按耐心程度决定要不要开。

打包与安装：见 `packaging/README.md`。

## 开发

```bash
python -m pip install -r requirements.txt
python -m pytest
```

## 目录结构

```
lyrics_extractor/     源码包
  audio_file.py       统一音频标签与内嵌歌词读取层（各容器适配）
  id3_reader.py       ID3 标签与 SYLT/USLT 内嵌歌词解析（mp3/wav/aiff 共用）
  lrc_writer.py       LRC 内容生成与文件写入
  online.py           lrclib.net 在线歌词客户端
  ai_transcribe.py    AI 听歌转写（OpenAI 兼容云端客户端 + 时间戳拼行）
  whisper_local.py    本机 Whisper 转写引擎（可选增强包）
  vocal_sep.py        Demucs 人声分离（可选增强包）
  settings.py         AI 服务设置的本机持久化
  extractor.py        单文件处理流水线（内嵌 → 在线 → AI 转写 → 写入）
  batch.py            指定文件列表 / 文件夹扫描的批量调度与失败清单导出
  gui.py              tkinter 界面（提取 + AI 兜底 + 预览确认 + 失败清单挑选）
tests/                pytest 测试
packaging/            PyInstaller 与 Inno Setup 打包脚本
```
